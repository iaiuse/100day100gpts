## 📌 What Is This

The prompt collection from [IAIUSE](https://iaiuse.com)'s "100 Days 100 GPTs" challenge. Each file is a complete [langgpt](https://github.com/langgptai/langgpt) system prompt (Role / Background / Attention / Profile / Skills / Goals / Constrains / Workflow / Suggestions).

Paste into ChatGPT GPTs Configure, Gemini Gems, or Claude Projects to use.

## 🚀 How to Use

1. Pick a model, open the file, copy everything.
2. Paste into your AI tool's system prompt box.
3. Start with a real decision you're wrestling with.
