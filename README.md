# 挑战100天100个GPTs · 思维模型提示词库

> [English](./README_EN.md) | 中文

86 个思维模型 GPT 提示词（langgpt 九段格式），覆盖芒格心理倾向、认知偏差、思维框架、系统战略、成长反脆弱、复杂性思维六大类。每个都经过 tavily 事实查证 + 归属诚实拆分。

## 📌 这是什么

[IAIUSE](https://iaiuse.com)「挑战100天100个GPTs」系列的提示词部分。每个文件是一套完整的 [langgpt](https://github.com/langgptai/langgpt) 系统提示词（角色/Background/Attention/Profile/Skills/Goals/Constrains/Workflow/Suggestions 九段）。

粘进 ChatGPT GPTs 的 Configure、Gemini Gems 或 Claude Projects 即可用。

## 🚀 怎么用

1. 选一个模型，打开文件，复制全部内容。
2. 粘进 AI 工具的系统提示框。
3. 丢一个你正纠结的真实决策开始对话。

## 🎯 归属与诚实

**每个提示词的 Background 段都做了归属诚实拆分**——区分"谁讲的"vs"学术源头"，标注证据层级，拿不准标"待核实"。

几个典型修正：
- 爱因斯坦"复利第八大奇迹" → 杜撰（Quote Investigator 证实）
- "刺激与反应之间有一道缝" → 非 Frankl 原著（Viktor Frankl Institute 确认）
- Baumeister 意志力电池 → 2016/2019 复现失败（d≈0.06）
- "100 个思维模型"清单 → 非芒格官方，是中文社区归纳
- de Bono 六顶帽"493% 效率" → 证据不足
